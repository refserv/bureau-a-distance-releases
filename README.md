# Bureau a distance — installateurs

Ce dépôt ne contient que les **installateurs** de l'application *Bureau a distance* (Reference Services) et les fichiers dont l'appli a besoin pour se **mettre à jour toute seule**. Le code source est privé.

**Télécharger la dernière version :** [page Releases](https://github.com/refserv/bureau-a-distance-releases/releases/latest)

| Système | Fichier |
|---|---|
| Windows | `Bureau-a-distance-<version>-Windows-Setup.exe` |
| macOS (Apple Silicon) | `Bureau-a-distance-<version>-macOS-arm64.dmg` |
| macOS (Intel) | `Bureau-a-distance-<version>-macOS-x64.dmg` |
| Linux | `Bureau-a-distance-<version>-Linux-x86_64.AppImage` |

Les installateurs ne sont pas encore signés : sous Windows, clique sur **Informations complémentaires → Exécuter quand même** ; sur Mac, fais **clic droit → Ouvrir** la première fois.

Les fichiers `latest*.yml` servent aux mises à jour automatiques : ne les supprime pas.
